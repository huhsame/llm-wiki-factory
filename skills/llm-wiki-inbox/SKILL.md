# 위키 자료 자동 수집

카톡과 메일을 위키 창고(`raw/`)로 **가져오기만** 하는 스킬이에요. 읽고 판정해서 페이지로 쓰는 건 `llm-wiki-factory`가 그대로 해요.

## 0. 네 가지 약속

1. **가져오기와 판정은 따로예요.** 이 스킬은 창고에 넣기만 해요. 자는 사이에 위키 페이지가 바뀌지 않아요.
2. **두 번 받아도 파일은 하나예요.** 몇 번을 돌려도 결과가 같아요.
3. **비밀번호는 화면에도 파일에도 안 남겨요.** 컴퓨터의 잠금 보관함에만 둬요.
4. **비밀번호는 제가 대신 치지 않아요.** 명령줄에 적거나(`--password` 같은 것) 앞에 `echo`를 붙여 흘려 넣지 않아요. 저장하는 한 줄은 **사용자가 직접 연 창에서** 쳐요(4절). 그래야 대화 기록에도 명령 기록에도 안 남아요.

## 1. 먼저 혼자 확인할 것 (묻지 않아요)

1. **위키 폴더** · 지금 열린 폴더에 `wiki/장부.md`가 있나요? 없으면 한 단계 위·아래를 한 번씩 봐요. 그래도 없으면 "위키를 먼저 만들까요?"라고 묻고 `llm-wiki-factory`로 넘겨요.
2. **카톡 스킬** · 두 곳을 봐요 · `%USERPROFILE%\.claude\skills\kakao-windows` 와 `<지금 폴더>\.claude\skills\kakao-windows`.
3. **파이썬** · `python --version` → `py -3 --version` → `python3 --version` 순서로 쳐 보고, **버전 글자가 찍힌 첫 명령**을 써요. 스토어 창이 열리거나 아무것도 안 나오면 가짜예요. 확실히 하려면 `python -c "import sys; print(sys.executable)"`로 **경로가 찍히는지** 봐요(9절).
4. **지메일 커넥터** · 이 대화에 Gmail 커넥터가 붙어 있나요? 붙어 있어도 **기본은 앱 비밀번호**예요. 커넥터는 앱 비밀번호가 막혔을 때만 써요.

## 2. 물어볼 것 (많아야 여섯 개, 하나씩)

**Q1. 무엇을 연결할까요?** ① 카톡 ② 메일 ③ 둘 다
**Q2. (메일) 어느 메일이에요?** ① 지메일 ② 네이버 ③ 회사·다른 메일
**Q3. (카톡) 어느 방을 모을까요?** · 방 목록을 먼저 보여주고 번호로 고르게 해요. "전부"도 보기에 넣어요.
**Q4. 예전 것은 어디까지 가져올까요?** ① 1개월 ② 6개월 ③ 1년 ④ 전부(최대 3년)
**Q5. 새로 오는 건 언제 가져올까요?** ① 말할 때만 ② 이 대화 여는 동안 한 시간마다 ③ 밤마다 자동(추천) ④ 나중에
**Q6. (Q5에서 ③일 때만) 보통 몇 시까지 컴퓨터를 켜 두세요?** · 그 시각으로 걸어요.

- **보기를 안 주고 묻지 않아요.** 자유 서술로 답하게 하면 막혀요. 모르겠다고 하시면 **제가 대신 확인**해요. 방 이름·설치 경로·2단계 인증 여부는 전부 제가 봐요.
- Q4에서 많이 고르셔도 놀라지 마세요 · **창고에 받아만 두고 회차마다 스무 건씩** 정리해요.

## 3. 카톡 연결

수업에서 받은 `kakao-windows` 스킬을 그대로 써요. **그 스킬은 안 고쳐요.**

1. `doctor` → `accounts` 로 상태와 계정을 봐요. **계정 폴더가 여럿이면 골라 주세요.** 고른 값은 뒤에 오는 명령마다 `--account` 로 같이 넘겨요.
2. 키가 없으면 `recover`. 이때는 카카오톡이 켜져 있어야 해요. 그래도 없으면 **그 방을 카톡에서 한 번 열고** 다시 `recover` 해요. 방을 열면 읽음 표시가 될 수 있어요.
3. `rooms` 로 최근 활동 순 방 목록을 뽑아 Q3을 물어요. **고른 방의 방 번호(chat_id)를 같이 적어 둬요.** 이름이 바뀌어도 그 번호로 계속 잡혀요.
4. `scripts/kakao_collect.py` 를 돌려요. 이게 `read` 를 **달마다 방마다 한 번씩** 부르고 결과를 창고로 옮겨요.

```
python "<스킬폴더>/scripts/kakao_collect.py" --wiki "C:/Users/나/Documents/내위키" --room "현장 단톡방" --room-id 12345678 --backfill-months 6
```

창고에 이렇게 쌓여요 · `raw/카톡/2026-09/현장 단톡방_5678.md` (한 달 한 방이 한 파일. 뒤 네 자리가 방 번호예요)

- **사진·파일은 안 들어와요. 글자만이에요.** 카톡 스킬이 원래 그래요.
- **한 방이 막혀도 나머지 방과 다음 달은 계속 돌아요.** 막힌 것은 결과의 `failed` 에 나와요. 그 방은 다음 회차에 그 자리부터 다시 해요.
- 그 스킬의 매시간 기능을 켜려면 `setup` 이 먼저예요. 카톡 스킬이 아예 없으면 `references/카톡연결.md` 끝의 「내보내기로 하는 법」을 보세요.

## 4. 메일 연결

기본은 **앱 비밀번호 + IMAP** 한 가지예요. 지메일·네이버·회사 메일이 같은 방법이에요.

| 메일 | 서버 | 미리 켤 것 |
|---|---|---|
| 지메일 | `imap.gmail.com` | 2단계 인증 → 앱 비밀번호 |
| 네이버 | `imap.naver.com` | **IMAP 사용함 + 동기화할 메일 수 5,000통** + (2단계면) 애플리케이션 비밀번호 |
| 회사·기타 | 관리자에게 물어봐요 | 회사마다 달라요 |

화면 위치는 `references/메일연결.md`에 적어 뒀어요. **네이버는 세 가지를 다 해야 해요.** 하나만 하면 안 돼요.

1. **이 한 줄만 사용자가 직접 여는 창에서 쳐요.** 제가 도구로 돌리면 입력 칸이 없어서 그냥 실패해요(0절 4번). Windows는 시작 단추를 누르고 `PowerShell` 을 치면 나오고, 위키 폴더 빈 곳에서 Shift+우클릭 해도 나와요. **붙여넣을 한 줄은 제가 경로까지 채워서 드려요.**
   ```powershell
   $pw = Read-Host -AsSecureString "앱 비밀번호"
   [Runtime.InteropServices.Marshal]::PtrToStringBSTR([Runtime.InteropServices.Marshal]::SecureStringToBSTR($pw)) | & "<파이썬>" "<스킬폴더>\scripts\secret_store.py" set --label "mail:me@example.com"
   ```
   macOS 터미널이면 이 한 줄이면 돼요. 치면 물어보고 **화면에 안 보여요.**
   ```
   python "<스킬폴더>/scripts/secret_store.py" set --label "mail:me@example.com"
   ```
2. 저장됐는지는 제가 `get --label "mail:me@example.com"` 으로 봐요. **있는지만 나오고 값은 안 나와요.**
3. 첫 수집.
   ```
   python "<스킬폴더>/scripts/mail_fetch.py" --wiki "C:/Users/나/Documents/내위키" --host imap.naver.com --user "me@example.com" --backfill-months 6
   ```

창고에 이렇게 쌓여요 · `raw/메일/2026-09/2026-09-14_a3f1b2c8_견적서 회신.md` (메일 하나가 한 파일)

- 받은편지함만 봐요. **읽음 표시를 바꾸지 않아요.**
- 첨부는 **이름만** 적어요. 파일은 안 받아요.
- 광고·알림은 `raw/메일/_걸러짐/`으로 보내요. **버리지 않아요.** "걸러진 거 봐줘"라고 하시면 제가 읽어 드려요.
- "이 쇼핑몰 메일은 빼줘"라고 하시면 **`<위키폴더>\.inbox\걸러낼도메인.txt`** 에 한 줄 더해요. 그 파일이 없으면 `templates/걸러낼도메인.txt`를 거기로 복사하고 적어요. 다음 수집부터 걸러져요.
- 앱 비밀번호를 못 받는 지메일이면 커넥터로 대신할 수 있어요. 그때는 빠질 수 있다고 꼭 말씀드려요(`references/메일연결.md`).

## 5. 두 트랙, 새로 오는 것과 밀린 것

**새로 오는 것** · 마지막으로 본 시각 이후만 가져와요. 빠뜨리지 않으려고 한 시간 겹쳐서 봐요. **여기서 받은 것만 "새로 온 것"으로 세요.**
**밀린 것** · 처음 연결할 때 고른 범위를 **오래된 달부터** 받아 둬요. 한 회차에 카톡은 월 파일 30개, 메일은 3개월치까지요. 과거분은 받은 즉시 "밀린 것"이에요.

받아 둔 것은 창고에만 있어요. 위키로 올리는 건 **"새로 넣은 자료 처리해줘"** 한 마디예요. 그때 `llm-wiki-factory`가 스무 건을 판정해요.

현황은 이렇게 알려 드려요.

> 새로 온 것 **3건** · 아직 안 들어간 것 **140건 중 20건**을 이번에 할 수 있어요.
> 예전 것은 **6개월 중 3개월치**를 받아 뒀어요.

숫자는 `scripts/inbox_status.py`가 세요. 제가 어림하지 않아요.

```
python "<스킬폴더>/scripts/inbox_status.py" --wiki "C:/Users/나/Documents/내위키"
```

- `ledger_found`가 `false`면 **장부 파일을 못 찾은 거예요.** 그때는 숫자를 읽어 드리지 말고 장부부터 찾아요.
- 한 달에 메일이 아주 많으면 그 달은 상한(400통)에 걸려요. 결과에 `truncated`가 나오면 그 달은 나눠서 다시 받아요.
- 상태는 `raw/_수집상태.json`에 있어요. **이름이 `_`로 시작하는 파일과 폴더는 자료가 아니에요.** 장부에도 안 올라가요. 자세한 것은 `references/상태와장부.md`에 있어요.

## 6. 자동으로 돌리기

| | 방식 | 도는 조건 | 비용 |
|---|---|---|---|
| ① | 말할 때만 | 제가 부를 때 | 대화 1회 |
| ② | 이 대화의 반복 작업 | 창을 열어 둔 동안, 최대 1주 | 반복마다 |
| ③ | **밤마다 가져오기만** | 컴퓨터가 켜져 있을 때 | **0** |
| ④ | 밤마다 판정까지 | `claude` 명령이 있을 때 | 밤마다 |

**③을 권해요.** 밤에는 가져오기만 하고 판단은 안 해요. 그래서 돈이 안 들고, 자는 사이에 위키가 바뀌지 않고, 아침에 "밀린 거 처리해줘" 한 마디면 끝나요.

`templates/야간수집.cmd` 를 **`<위키폴더>\.inbox\` 안에** 복사하고 `SKILL`·`PY` 두 줄만 채워요. 위키 경로는 파일이 놓인 자리에서 저절로 잡혀요. **그 두 줄은 제가 이 컴퓨터의 진짜 절대경로를 찾아 채워 넣어요.** 플러그인으로 까셨으면 스킬이 `.claude\skills\` 가 아니라 `.claude\plugins\` 밑에 있어요.

```powershell
$cmd = "C:\Users\나\Documents\내위키\.inbox\야간수집.cmd"
$action  = New-ScheduledTaskAction -Execute $cmd
$trigger = New-ScheduledTaskTrigger -Daily -At "23:00"
$set     = New-ScheduledTaskSettingsSet -StartWhenAvailable -AllowStartIfOnBatteries -DontStopIfGoingOnBatteries
Register-ScheduledTask -TaskName "내위키 야간수집" -Action $action -Trigger $trigger -Settings $set -Force
```

**등록했다고 끝이 아니에요.** 한 번 돌려 보고 창고에 파일이 생기는 것까지 봐요.

```powershell
Start-ScheduledTask -TaskName "내위키 야간수집"
Get-ScheduledTaskInfo -TaskName "내위키 야간수집" | Select-Object LastRunTime, LastTaskResult
```

`LastTaskResult`가 `0`이면 **작업이 돌았다는 뜻**이에요. 잘 됐는지는 두 가지로 봐요 · ① 창고에 파일이 늘었는지 ② `<위키폴더>\.inbox\collect.log` 마지막 줄의 `mail=`·`kakao=`가 둘 다 `0`인지요. `2`면 한쪽이 막힌 거고 그 줄 위에 이유가 적혀 있어요. 끄는 법과 macOS 방법, ②·④의 명령은 `references/자동화.md`에 있어요.

**미리 말씀드릴 것 셋** · ① 컴퓨터가 꺼져 있으면 안 돌아요 ② **대화를 풀 키를 아직 못 받았으면 카톡은 건너뛰어요.** 한 번 `recover`로 키를 받아 두면 그다음부터는 카카오톡이 꺼져 있어도 모아져요 ③ 그래서 컴퓨터를 켜 두시는 시각으로 걸어요.

## 7. 비밀번호

- Windows는 **그 사용자 계정만 풀 수 있는 잠금**으로 **내 사용자 폴더 안** `.llm-wiki-inbox\secrets.dat`에 둬요. 다른 PC로 복사해도 보통은 안 풀려요(회사에서 한 계정을 여러 PC로 옮겨 쓰는 경우만 예외예요). macOS는 키체인이에요.
- **화면에 안 찍고, 위키·장부·기록·상태 파일 어디에도 안 적어요.** 상태 파일에는 이름표만 있어요.
- **제가 대신 치지 않아요.** 실수로 대화에 붙여넣으셨으면 **그 비밀번호를 지우고 새로 받으세요.** 제가 그 값을 어디에도 옮기지 않아요.
- 저장만 하고 "됐어요"라고 안 해요. 실제로 한 번 접속해 보고 말씀드려요.
- 위키 폴더에 `.gitignore`가 있으면 `.llm-wiki-inbox/`·`.inbox/`·`raw/_수집상태.json` 세 줄을 넣어 둬요.

## 8. 위키에 안 옮기는 것

- **연락처는 창고에만 둬요.** 전화번호와 개인 메일 주소는 위키 페이지에 안 적어요. 이름·소속·직함·정해진 사실은 그대로 둬요(`llm-wiki-factory` 규칙 그대로예요).
- **카톡은 고르신 방만** 가져와요. 전체를 기본으로 쓰지 않아요. 메일 첨부는 이름만 적어요.
- `_걸러짐`은 지우지 않아요. 광고인 줄 알았던 게 계약 안내일 때가 있어요.

## 9. 막혔을 때

- **네이버가 안 돼요** · 세 가지를 다 하셨나요? ① IMAP 사용함 ② 동기화할 메일 수 ③ 애플리케이션 비밀번호. 지문·얼굴 로그인(패스키)은 프로그램에 못 넣어요.
- **비밀번호가 틀렸대요** · 평소 비밀번호 말고 **앱 비밀번호 16자리**를 공백 없이요.
- **`EMPTY_SECRET`이 나왔어요** · 제가 그 명령을 대신 돌린 거예요. 4절 1번대로 **직접 창을 열어** 쳐 주세요.
