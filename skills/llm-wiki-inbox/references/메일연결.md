# 메일 연결

기본은 **앱 비밀번호 + IMAP** 하나예요. 지메일·네이버·회사 메일이 같은 방법이에요.

## 1. 앱 비밀번호가 뭔가요

평소 로그인 비밀번호 대신 **프로그램 하나에만 쓰는 딴 비밀번호**예요. 보통 16자리 글자고요.

- 프로그램에만 쓰니까 다른 곳에 새지 않아요.
- 싫어지면 **그 줄만 지우면** 돼요. 평소 비밀번호는 그대로 두고요.
- **지문·얼굴 로그인(패스키)은 앱 비밀번호가 아니에요.** 그건 프로그램에 못 넣어요. 우리가 받을 건 **글자**예요.

받아 오시면 **대화창에 붙여넣지 마세요.** Claude 가 대신 쳐 줄 수도 없어요. 도구로 돌리면 입력 칸이 없어서 `EMPTY_SECRET` 으로 끝나거든요.

**직접 창을 하나 여세요.** Windows 는 시작 단추를 누르고 `PowerShell` 이라고 치면 나와요. 위키 폴더 빈 곳에서 Shift+우클릭 해도 나오고요. 거기에 이 한 줄을 붙여넣고 엔터를 누르면 비밀번호를 물어보는데, **글자가 화면에 안 보이는 게 정상**이에요.

```powershell
$pw = Read-Host -AsSecureString "앱 비밀번호"
[Runtime.InteropServices.Marshal]::PtrToStringBSTR([Runtime.InteropServices.Marshal]::SecureStringToBSTR($pw)) | & "<파이썬>" "<스킬폴더>\scripts\secret_store.py" set --label "mail:me@example.com"
```

`<파이썬>` 과 `<스킬폴더>` 는 Claude 가 이 컴퓨터의 진짜 경로로 채워서 드려요. 스킬 폴더는 `%USERPROFILE%\.claude\skills\llm-wiki-inbox` 예요(실습 폴더 안에 두셨으면 그 폴더의 `.claude\skills\`, macOS는 `~/.claude/skills/llm-wiki-inbox`). macOS 터미널이면 더 짧아요.

```
python "<스킬폴더>/scripts/secret_store.py" set --label "mail:me@example.com"
```

- **비밀번호를 명령 뒤에 붙여 적지 마세요.** 명령 기록에 남아요. `echo` 로 흘려 넣는 것도 같아요.
- 저장됐는지는 Claude 가 `get --label ...` 로 봐요. **있는지만 나오고 값은 안 나와요.**

## 2. 화면 위치 세 가지

### 지메일 (`@gmail.com`)

| 순서 | 어디를 누르나 |
|---|---|
| 1 | 구글 계정 → **보안** |
| 2 | **2단계 인증**을 먼저 켜요. 이게 꺼져 있으면 앱 비밀번호 메뉴가 아예 안 보여요 |
| 3 | 같은 보안 화면에서 **앱 비밀번호** (바로 가려면 `myaccount.google.com/apppasswords`) |
| 4 | 이름을 `내위키`라고 적고 만들기 → 나오는 **16자리**를 복사 |

- 서버는 `imap.gmail.com`, 포트 993이에요.
- **회사·학교 지메일은 관리자가 앱 비밀번호를 막아 둘 수 있어요.** 그 화면이 안 열리면 4절 커넥터 경로로 가요.

### 네이버 (`@naver.com`) · **세 가지를 다 해야 해요**

| 해야 할 것 | 화면 위치 |
|---|---|
| ① IMAP 켜기 | 네이버 메일 → 왼쪽 아래 **환경설정** → **POP3/IMAP 설정** → **IMAP/SMTP 설정** 탭 → **사용함** → 저장 |
| ② 동기화할 메일 수 | **같은 화면**에서 가장 큰 값(**5,000통**)으로 두세요. 기본값이면 옛 메일이 아예 안 잡혀요 |
| ③ 애플리케이션 비밀번호 | 네이버 → 프로필 → **네이버ID** → **보안 설정** → 2단계 인증 **관리** → 비밀번호 한 번 더 입력 → **애플리케이션 비밀번호 관리** → **직접 입력** → 이름 `내위키` → **생성하기** |

- **하나만 하면 안 돼요.** IMAP을 안 켜면 로그인은 되는데 받은편지함을 못 열어요.
- ③은 보안 설정 화면 안에서 바로 안 보여요. **2단계 인증의 「관리」로 들어가야** 나와요.
- 2단계 인증을 안 쓰시면 ③ 메뉴가 **안 보여요.** 그때는 네이버 로그인 비밀번호를 그대로 쓰세요.
- 서버는 `imap.naver.com`, 포트 993이에요.

### 회사 메일·그 밖

| 물어볼 것 | 이렇게 물어보세요 |
|---|---|
| IMAP 주소 | "메일을 아웃룩 같은 프로그램에 연결하려는데 **IMAP 서버 주소**가 뭔가요?" |
| 포트 | 보통 993이에요. 다르면 알려 달라고 해요 |
| 앱 비밀번호 | 회사마다 달라요. 없으면 평소 비밀번호로 되는 곳도 있어요 |

- 다음(`@daum.net`)은 네이버와 비슷해요. 메일 환경설정에서 IMAP을 켜고 서버는 `imap.daum.net`이에요.
- 아웃룩·오피스365는 회사 정책에 따라 앱 비밀번호가 막혀 있는 경우가 많아요. 관리자에게 먼저 물어보세요.

## 3. 첫 수집

```
python "<스킬폴더>/scripts/mail_fetch.py" --wiki "C:/Users/나/Documents/내위키" --host imap.naver.com --user "me@example.com" --backfill-months 6
```

그다음부터는 이렇게만 하면 돼요.

```
python "<스킬폴더>/scripts/mail_fetch.py" --wiki "C:/Users/나/Documents/내위키" --all
```

접속 없이 설정만 확인하고 싶으면 `--dry-run`을 붙여요. 어느 구간을 볼 건지와 비밀번호가 저장돼 있는지만 알려 줘요.

## 4. 앱 비밀번호가 막혔을 때 (대체 경로 둘)

| 순위 | 경로 | 언제 쓰나 | 결과가 매번 같나 |
|---|---|---|---|
| **1** | **IMAP 스크립트**(기본) | 앱 비밀번호를 받을 수 있는 모든 메일 | 같아요 |
| 2 | Claude의 Gmail 커넥터 | 관리자가 앱 비밀번호를 막은 지메일 | **다를 수 있어요.** 검색으로 찾는 방식이라 회차마다 집는 메일이 달라질 수 있어요 |
| 3 | `gws` 명령 | 이미 gws를 붙여 둔 분 | 중간. Node를 깔아야 하고 일부 노트북은 설치가 막혀요 |

**커넥터로 할 때 지킬 것**
- 마지막으로 본 시각 이후 메일을 읽어 **같은 형식으로** `raw/메일/{연-월}/`에 써요. 파일 이름의 여덟 글자는 커넥터가 주는 메시지 번호를 줄인 값이에요.
- 상태 파일에 `"mode": "connector"`, `"deterministic": false`를 적어요.
- 보고할 때 한 줄 덧붙여요 · **"커넥터로 가져와서 빠진 게 있을 수 있어요. 정확히 하려면 앱 비밀번호 방식을 권해요."**

## 5. 오류 문구별 다음 행동

| 서버가 하는 말 | 무슨 뜻 | 다음 행동 |
|---|---|---|
| `AUTHENTICATIONFAILED` / `Invalid credentials` | 앱 비밀번호가 아니라 평소 비밀번호를 넣었어요 | 앱 비밀번호 화면으로 다시. **16자리를 공백 없이** |
| `Application-specific password required` | 2단계 인증이 켜져 있어요 | 앱 비밀번호를 발급받아요 |
| `IMAP access is disabled` · 로그인은 되는데 받은편지함에서 실패 | 메일함에서 IMAP을 안 켰어요 | 네이버·다음은 환경설정에서 IMAP 켜기 |
| `timed out` · 연결 자체가 안 됨 | 회사망이 993 포트를 막았어요 | 집이나 휴대전화 테더링으로 한 번. 그래도 막히면 4절 커넥터 경로 |
| `Too many simultaneous connections` | 다른 메일 프로그램이 같은 계정을 붙들고 있어요 | 아웃룩 등을 닫고 1분 뒤 다시 |
| 로그인은 되는데 메일이 0건 | 받은편지함이 아니라 다른 폴더로 와요 | 지금은 받은편지함만 봐요. 그대로 두세요 |
| `NO_SECRET` | 비밀번호가 저장돼 있지 않아요 | `secret_store.py set` 을 먼저 |
| `EMPTY_SECRET` | Claude 가 저장 명령을 대신 돌렸어요 | 1절대로 **직접 창을 열어** 그 한 줄을 치세요 |
| `NO_WIKI` | 위키 폴더를 잘못 가리켰어요 | `wiki/` 가 있는 폴더를 `--wiki` 로 |
| 한글 제목이 `=?UTF-8?B?…`로 보임 | 풀리지 않은 거예요 | 스크립트 문제예요. 강사에게 알려 주세요 |

## 6. 알아 두실 것

- **받은편지함만** 봐요. 보낸편지함은 이번 판에 없어요.
- **읽음 표시를 바꾸지 않아요.** 읽기 전용으로 열고, 메일을 가져올 때도 읽음으로 바꾸지 않는 방식을 써요.
- 본문은 20,000자까지 저장해요. 그보다 길면 뒤가 잘려요.
- 한 달에 메일이 아주 많으면 그 달은 한 번에 400통까지만 봐요. 그러면 결과에 `truncated` 가 나와요. 조용히 버리지 않고 알려 드려요.
- 날짜 헤더가 깨진 메일은 서버가 준 도착 시각으로 대신해요. 그것도 없으면 `dropped` 로 세어서 알려 드려요.
- 첨부는 **이름만** 적어요. 파일은 안 받아요. 용량과 개인정보 때문이에요.
- 같은 메일은 항상 같은 파일 이름이 돼요. 이미 있으면 건너뛰어요. 그래서 몇 번을 돌려도 안전해요.
