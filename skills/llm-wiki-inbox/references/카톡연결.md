# 카톡 연결

수업에서 받은 **`kakao-windows`** 스킬을 그대로 써요. 그 스킬은 안 고치고, 결과만 위키 창고로 옮겨요.
카카오톡 데이터베이스를 우리가 직접 여는 일은 없어요.

## 1. 스킬이 어디 깔렸는지 찾기 (제가 해요)

두 곳을 봐요. 사용자에게 경로를 묻지 않아요.

```
%USERPROFILE%\.claude\skills\kakao-windows
<지금 열린 폴더>\.claude\skills\kakao-windows
```

`tool\entrypoint.py` 가 있는 쪽이 진짜예요. 둘 다 없으면 이 문서 맨 아래 「내보내기로 하는 법」으로 가요.

스킬을 부르는 방법은 이래요.

```powershell
& "<스킬폴더>\tool\.venv\Scripts\python.exe" "<스킬폴더>\tool\entrypoint.py" doctor
```

macOS에서는 카톡 수집이 안 돼요. `kakao-windows`가 Windows 전용이에요.

## 2. 처음 연결할 때 순서

| 순서 | 명령 | 보는 것 |
|---|---|---|
| 1 | `doctor` | 카카오톡이 켜져 있나, 준비가 됐나 |
| 2 | `accounts` | 계정 폴더가 여럿이면 어느 것인지. 고른 값은 뒤 명령마다 `--account <값>` 으로 붙여요 |
| 3 | `recover` | 대화를 풀 키가 없을 때만. **이때만** 카카오톡이 켜져 있어야 해요 |
| 4 | `rooms` | 방 목록. 최근에 말이 오간 순서로 나와요. **`chat_id` 를 같이 적어 둬요** |
| 5 | `setup --room "정확한 방 이름"` | 5절의 매시간 기능을 켤 때만. 안 해 두면 `SETUP_REQUIRED` 가 나요 |

**키를 받을 때는 카카오톡 PC가 켜져 있어야 해요.** 한 번 받아 두면 그다음부터는 꺼져 있어도 읽혀요.

`rooms` 결과에서 최근 열 개를 번호로 보여 드리고 고르게 해요. **사용자가 방 이름을 타이핑하지 않게 해요.** 한 글자만 달라도 안 잡혀요. 고른 방의 `chat_id` 를 등록에 같이 넘기면 **나중에 방 이름이 바뀌어도** 계속 잡혀요.

## 3. 창고로 옮기기

```
python "<스킬폴더>/scripts/kakao_collect.py" --wiki "C:/Users/나/Documents/내위키" --room "현장 단톡방" --room-id 12345678 --backfill-months 6
```

계정이 여럿이면 `--account <accounts 에서 고른 값>` 을 같이 붙여요.

그다음부터는 이렇게만요.

```
python "<스킬폴더>/scripts/kakao_collect.py" --wiki "C:/Users/나/Documents/내위키" --all
```

카톡을 부르지 않고 계획만 보려면 `--dry-run`을 붙여요.

**무슨 일이 일어나나** · 달마다 방마다 한 번씩 `read --start ... --end ...` 를 불러서 그 달을 통째로 다시 써요.
창이 항상 **달의 첫날부터 그 달 마지막 순간까지**라 덮어써도 잃는 메시지가 없어요. 그래서 몇 번을 돌려도 결과가 같아요.
**방마다 따로 부르는 이유** · 한 방이 막혀도 나머지 방과 다음 달이 계속 돌게 하려는 거예요. 막힌 것은 결과의 `failed` 에 나오고, 그 방의 커서는 안 올라가요. 다음 회차에 그 자리부터 다시 해요.

**파일 모양** · `raw/카톡/2026-09/현장 단톡방_5678.md` (뒤 네 자리는 방 번호예요)

```markdown
---
방: 현장 단톡방
달: 2026-09
메시지: 3
수집: 2026-09-19 23:04
---

- **09-01 10:12** [김선영] 견적서 오늘 중으로 보내드릴게요
- **09-01 10:14** [나] 네 확인하고 회신드리겠습니다
```

- 머리의 `메시지:` 는 **실제로 적힌 줄 수**예요. 화면에 보고되는 숫자도 같은 수예요.
- 시각은 이 컴퓨터 시각으로 `MM-DD HH:MM` 이에요.
- 본인이 보낸 줄은 `[나]` 예요.
- 줄바꿈이 든 메시지는 한 줄로 펴요. 빈 메시지는 빼요. `[삭제된 메시지]`는 그대로 둬요.
- 방 이름에 `\ / : * ? " < > |` 가 있으면 파일 이름에서 빼요. 한글은 그대로 둬요. 이름이 같은 방이 둘이면 뒤의 방 번호로 갈려요.
- **사진·파일의 내용은 안 들어와요. 글자만이에요.**

**한 회차에 만드는 파일은 30개까지**예요. 오래된 달부터 채우고 남으면 다음 회차에 이어서 해요.

## 4. 오류 코드별 다음 행동

오류 글자는 `failed` 안의 `message` 에 그대로 실려 와요.

| 코드 | 뜻 | 다음 행동 |
|---|---|---|
| `KEYS_REQUIRED` | 대화를 풀 키가 아직 없어요 | 카카오톡을 켜고 `recover` → 그래도 없으면 **그 방을 카톡에서 한 번 열고** 다시 `recover`. 방을 열면 읽음 표시가 될 수 있다고 먼저 말씀드려요 |
| `KEY_CACHE_UNREADABLE` | 저장해 둔 키를 못 읽어요 | 같은 Windows 계정인지 보고, `recover` 를 한 번 더 |
| `NO_ACCOUNT` | 카톡 계정 폴더를 못 찾았어요 | 카카오톡에 한 번 로그인하고 `accounts` 다시 |
| `ACCOUNT_REQUIRED` | 계정 폴더가 여럿이에요 | `accounts` 결과를 보여 드리고 고르게 한 뒤 `--account` 로 넘겨요 |
| `Room was not found by exact name or chat_id` | 방 이름이 바뀌었거나 오타예요 | `rooms` 로 다시 보고 **`chat_id` 로** 등록해요 |
| `SETUP_REQUIRED` | 5절 매시간 기능을 켜려는데 설정이 없어요 | `setup --room "정확한 방 이름"` 을 한 번 돌리고 다시요 |
| `OUTPUT_NOT_EMPTY` | 결과 폴더가 비어 있지 않아요 | 매번 새 임시 폴더를 쓰니 보통 안 나요. 나면 그 폴더를 지우고 다시요 |
| `WINDOWS_REQUIRED` | Windows 가 아니에요 | macOS 에서는 카톡 수집이 안 돼요. 메일만이에요 |
| `KAKAO_SKILL_NOT_FOUND` | 카톡 스킬을 못 찾았어요 | 1절의 두 곳을 다시 보고, 없으면 아래 「내보내기로 하는 법」 |
| `KAKAO_VENV_MISSING` | 스킬은 있는데 준비가 덜 됐어요 | **kakao-windows 스킬 문서의 설치 절을 그대로** 따라요. 우리가 새 안내를 지어내지 않아요 |
| `missing_rooms` 에 방이 남음 | 그 방은 이번에 못 읽었어요 | 정상적인 부분 성공이에요. 그 방을 카톡에서 한 번 열면 다음 회차에 잡혀요 |

## 5. 카톡 스킬이 낮 동안 기록을 모으게 하기 (선택)

**먼저 `setup` 이 되어 있어야 해요.** 안 돼 있으면 `SETUP_REQUIRED` 가 나요. 그때는 `setup --room "정확한 방 이름"` 을 한 번 돌리고 다시 `schedule --enable` 하세요.

`kakao-windows`에는 매시간 도는 기능이 있어요. 켜 두면 **낮 동안 대화를 풀 키를 미리 확보해 둬서** 밤 수집이 덜 비어요.

```powershell
& "<스킬폴더>\tool\.venv\Scripts\python.exe" "<스킬폴더>\tool\entrypoint.py" schedule --enable
& "<스킬폴더>\tool\.venv\Scripts\python.exe" "<스킬폴더>\tool\entrypoint.py" schedule --status
& "<스킬폴더>\tool\.venv\Scripts\python.exe" "<스킬폴더>\tool\entrypoint.py" schedule --disable
```

매시간 작업이 모은 기록 자체는 **그 스킬 자기 폴더에만** 남아요. 우리 창고로 옮기는 건 여전히 `kakao_collect.py` 가 그때그때 `read` 를 불러서 해요.

## 6. 카톡 스킬이 없을 때 (내보내기로 하는 법)

손으로 하는 방법이에요. 증분도, 자동도 없어요.

1. 카카오톡 PC에서 모을 방을 열어요.
2. 오른쪽 위 메뉴 → **대화 내보내기** → **텍스트만** 저장.
3. 저장한 `.txt` 를 `raw/카톡/` 폴더 안에 넣어요. 폴더가 없으면 만들어요.
4. **"위키에 넣어줘"** 라고 하면 `llm-wiki-factory` 가 평소처럼 읽어요.

파일 이름은 `방이름_2026-09.txt` 처럼 방과 시기를 알아볼 수 있게 두세요. 나중에 같은 방을 또 내보내면 **먼젓번 파일은 그대로 두고** 새 파일로 넣으세요. 이름이 다르면 둘 다 새 자료로 잡히니, 겹치는 기간은 피해서 내보내시는 게 좋아요.
