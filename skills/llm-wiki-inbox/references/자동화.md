# 자동으로 돌리기 · 네 가지

| | 방식 | 도는 조건 | 비용 | 언제 |
|---|---|---|---|---|
| ① | 말할 때만 | 부를 때 | 대화 1회 | 기본값 |
| ② | 이 대화의 반복 작업 | 창을 열어 둔 동안, 최대 1주 | 반복마다 | 그날 하루 지켜볼 때 |
| ③ | **밤마다 가져오기만** | 컴퓨터가 켜져 있을 때 | **0** | **추천** |
| ④ | 밤마다 판정까지 | `claude` 명령이 있을 때 | 밤마다 | 비추천 |

## ③을 권하는 이유 다섯

1. **밤에 도는 건 가져오기뿐이고 판단이 없어요.** 자는 사이에 위키 페이지가 바뀌지 않아요.
2. **돈이 안 들어요.** 스크립트만 도니까요.
3. **아침에 할 일이 한 마디예요.** "밀린 거 처리해줘" 하면 그날 스무 건이 정리돼요.
4. **망가져도 되돌리기 쉬워요.** 창고에 파일만 늘어난 상태라 지우면 끝이에요.
5. ②는 창을 닫으면 멈춰요. ④는 밤중에 확인 창이 뜨면 그대로 멈춰 있어요.

---

## ① 말할 때만

```
python "<스킬폴더>/scripts/mail_fetch.py"    --wiki "C:/Users/나/Documents/내위키" --all
python "<스킬폴더>/scripts/kakao_collect.py" --wiki "C:/Users/나/Documents/내위키" --all
python "<스킬폴더>/scripts/inbox_status.py"  --wiki "C:/Users/나/Documents/내위키"
```

"새 메일 가져와"·"카톡 새로 온 거 가져와"라고 하시면 이걸 돌리고 몇 건인지만 알려 드려요.

## ② 이 대화의 반복 작업

수업에서 배운 그대로예요. 창이 열려 있는 동안만 돌고, 최대 1주, 창을 닫으면 멈춰요.

```
/loop 1h 새로 온 카톡과 메일을 가져오고, 새 게 있으면 몇 건인지만 알려줘
```

끄려면 지금 걸린 반복 작업 목록을 보고 그것만 취소해요.
**이미 ③을 걸어 뒀으면 ②를 겹쳐 걸지 않아요.** 두 번 돌아도 결과는 같지만 쓸데없이 돌아요.

## ③ 밤마다 가져오기만 (Windows)

### (가) 실행 파일 하나를 먼저 만들어요

따옴표가 꼬이지 않게 명령을 파일에 넣어요. `templates/야간수집.cmd` 를 그대로 복사하고 **두 줄만** 바꾸면 돼요.

저장 위치 · `<위키폴더>\.inbox\야간수집.cmd` · **이 자리에 두어야 해요.** 위키 경로를 파일이 놓인 자리에서 스스로 찾거든요.

```bat
@echo off
chcp 65001 >nul
for %%I in ("%~dp0..") do set "WIKI=%%~fI"
set "SKILL=C:\Users\me\.claude\skills\llm-wiki-inbox"
set "PY=C:\Users\me\AppData\Local\Programs\Python\Python312\python.exe"

set "LOG=%~dp0collect.log"
echo [%date% %time%] start >> "%LOG%"
"%PY%" "%SKILL%\scripts\mail_fetch.py"    --wiki "%WIKI%" --all >> "%LOG%" 2>&1
set "RC1=%ERRORLEVEL%"
"%PY%" "%SKILL%\scripts\kakao_collect.py" --wiki "%WIKI%" --all >> "%LOG%" 2>&1
set "RC2=%ERRORLEVEL%"
echo [%date% %time%] end mail=%RC1% kakao=%RC2% >> "%LOG%"
if not "%RC1%"=="0" exit /b %RC1%
exit /b %RC2%
```

- `%PY%` 와 `%SKILL%` 은 이 컴퓨터에서 실제로 찾은 **전체 경로**예요. `python` 이라고만 적지 않아요. 예약 작업은 PATH가 다르거든요. 스킬 폴더는 `%USERPROFILE%\.claude\skills\llm-wiki-inbox` 예요(실습 폴더 안에 두셨으면 그 폴더의 `.claude\skills\`). macOS는 `~/.claude/skills/llm-wiki-inbox` 예요.
- **파일 안은 전부 영문이에요.** 한글 폴더 이름(`내위키`)을 이 파일에 적지 않아도 되게 만든 거예요. 배치 파일과 한글은 사이가 나빠요.
- 한 줄이 실패해도 다음 줄이 돌아요. 대신 **두 줄의 결과를 모아 종료코드로 내보내요.** 그래야 밤새 실패한 걸 알 수 있어요.

### (나) 예약 등록 (PowerShell)

```powershell
$cmd = "C:\Users\나\Documents\내위키\.inbox\야간수집.cmd"
$action  = New-ScheduledTaskAction -Execute $cmd
$trigger = New-ScheduledTaskTrigger -Daily -At "23:00"
$set     = New-ScheduledTaskSettingsSet -StartWhenAvailable -AllowStartIfOnBatteries -DontStopIfGoingOnBatteries -ExecutionTimeLimit (New-TimeSpan -Minutes 30)
Register-ScheduledTask -TaskName "내위키 야간수집" -Action $action -Trigger $trigger -Settings $set -Description "llm-wiki-inbox 야간 수집(가져오기만)" -Force
```

### (다) 등록만 하고 끝내지 않아요

```powershell
Get-ScheduledTask -TaskName "내위키 야간수집" | Select-Object TaskName, State
Start-ScheduledTask -TaskName "내위키 야간수집"
Get-ScheduledTaskInfo -TaskName "내위키 야간수집" | Select-Object LastRunTime, LastTaskResult, NextRunTime
```

`LastTaskResult` 가 `0` 이면 **둘 다 됐다는 뜻**이에요. `2` 면 한쪽이 막힌 거예요.

막혔으면 `<위키폴더>\.inbox\collect.log` 의 **맨 아래 줄**을 봐요. `end mail=0 kakao=2` 처럼 어느 쪽인지 적혀 있고, 그 위에 이유가 JSON 한 줄로 남아 있어요. 그리고 **창고에 파일이 실제로 늘었는지**까지 보고 말씀드려요.

### (라) 끄기

```powershell
Disable-ScheduledTask -TaskName "내위키 야간수집"
Unregister-ScheduledTask -TaskName "내위키 야간수집" -Confirm:$false
```

앞은 잠깐 멈춤, 뒤는 아예 지우기예요.

### (마) 옛 명령으로 하고 싶으면

같은 일을 하는 `schtasks` 예요. PowerShell에서는 따옴표가 자주 깨지니 **`cmd` 창에서** 치세요.
`/RU` 와 `/IT` 를 빼면 **암호를 물어보며 멈출 수 있어요.** 위 PowerShell 쪽을 쓰면 이 문제가 없어요.

```
schtasks /Create /TN "내위키 야간수집" /TR "\"C:\Users\나\Documents\내위키\.inbox\야간수집.cmd\"" /SC DAILY /ST 23:00 /RU "%USERNAME%" /IT /RL LIMITED /F
schtasks /Query  /TN "내위키 야간수집" /V /FO LIST
schtasks /Run    /TN "내위키 야간수집"
schtasks /Delete /TN "내위키 야간수집" /F
```

### 꼭 말씀드릴 한계 셋

1. **컴퓨터가 꺼져 있거나 덮여 있으면 안 돌아요.** 다음에 켰을 때 한 번 몰아서 돌아요.
2. **대화를 풀 키를 아직 못 받았으면 카톡은 건너뛰어요.** 한 번 `recover` 로 키를 받아 두면 그다음부터는 카카오톡이 꺼져 있어도 모아져요. 키를 받는 그 한 번만 카카오톡이 켜져 있어야 해요.
3. 로그인한 계정으로만 돌아요. 로그아웃하면 안 돌아요. 그래서 새벽이 아니라 **컴퓨터를 켜 두시는 시각**으로 걸어요.

## ③ 밤마다 가져오기만 (macOS)

**먼저 한 가지** · 위키 폴더를 **문서·바탕화면·다운로드 안에 두면 밤 작업이 막혀요.** 예약으로 뜬 프로그램은 그 세 폴더를 못 열고, 허용 창도 안 뜨고 조용히 실패해요. 홈 바로 아래(`/Users/나/내위키`)에 두세요.

`~/Library/LaunchAgents/com.mywiki.nightly.plist`

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0"><dict>
  <key>Label</key><string>com.mywiki.nightly</string>
  <key>ProgramArguments</key>
  <array>
    <string>/usr/bin/python3</string>
    <string>/Users/나/.claude/skills/llm-wiki-inbox/scripts/mail_fetch.py</string>
    <string>--wiki</string><string>/Users/나/내위키</string>
    <string>--all</string>
  </array>
  <key>StartCalendarInterval</key><dict><key>Hour</key><integer>23</integer><key>Minute</key><integer>0</integer></dict>
  <key>StandardOutPath</key><string>/Users/나/내위키/.inbox/collect.log</string>
  <key>StandardErrorPath</key><string>/Users/나/내위키/.inbox/collect.log</string>
</dict></plist>
```

```bash
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.mywiki.nightly.plist
launchctl kickstart -k gui/$(id -u)/com.mywiki.nightly
launchctl print gui/$(id -u)/com.mywiki.nightly | head -20
launchctl bootout gui/$(id -u)/com.mywiki.nightly
```

- **맥에 개발자 도구가 없으면 `/usr/bin/python3` 가 설치 안내만 띄우고 실패해요.** `which python3` 로 나온 경로를 그대로 적어 주세요.

더 간단하게는 `crontab -e` 에 한 줄이면 돼요. 여기도 위키 폴더가 문서·바탕화면 밖이어야 해요.

```
0 23 * * * /usr/bin/python3 ~/.claude/skills/llm-wiki-inbox/scripts/mail_fetch.py --wiki ~/내위키 --all
```

macOS에서는 카톡 수집이 안 돼요. 메일만이에요.

## ④ 밤에 판정까지 (기본은 안 권해요)

`claude` 명령이 깔린 분만 할 수 있어요. `.cmd` 에 한 줄을 더해요.

```bat
claude -p "새로 들어온 자료 처리해줘" 1>> "%LOG%" 2>&1
```

**먼저 알려 드릴 것 셋**

1. 밤마다 사용량이 깎여요.
2. **확인 창이 뜨면 아무도 못 눌러서 그대로 멈춰 있어요.** 미리 허용해 두려면 `--permission-mode` 를 쓰는데, 판마다 쓸 수 있는 값이 달라요. `claude --help` 로 한 번 확인하세요.
3. 자는 사이에 위키 페이지가 바뀌어요. `llm-wiki-factory` 의 「자동은 판정까지만」과 어긋나요.

그래서 **먼저 ③으로 2주쯤 굴려 보시고**, 그래도 아침 한 마디가 귀찮으시면 그때 바꾸시는 걸 권해요.

## 수집 로그가 커지면

`<위키폴더>\.inbox\collect.log` 가 10MB를 넘으면 `collect-old.log` 로 한 번 옮기고 새로 시작해요.
