# 세는 법과 고르는 순서

숫자를 어림하지 않기 위한 문서예요. **진단(`references/진단과이음.md`)과 점검(SKILL.md 8절)이 같은 방식으로 세요.** 다르게 세면 숫자가 어긋나서 사용자가 둘 다 못 믿어요.

## 1. 양쪽에서 똑같이 빼고 세는 것

- **뼈대 파일 넷** · `index.md` · `log.md` · `tags.md` · `장부.md`. 이 넷은 페이지가 아니에요
- **이름이 `_`로 시작하는 파일과 폴더** · `_둘러보기.md` · `_수집상태.json` · `_걸러짐/`
- **한쪽에서만 빼면 안 돼요.** 파일 쪽에서만 빼면 늘 "목차에 없는 페이지 4장"이, 목차 쪽에서만 빼면 늘 "파일 없는 줄 4개"가 나와요
- 한글 이름은 **양쪽 다 같은 형태(NFC)로 맞춰서** 비교해요(SKILL.md 11절)

## 2. 무엇과 무엇을 견주나

| 세는 것 | 왼쪽 | 오른쪽 |
|---|---|---|
| ① 목차에 없는 페이지 | `wiki/` 안 `.md` 파일 이름 | `index.md`의 `[[링크]]` |
| ② 목차에 있는데 파일이 없는 줄 | `index.md`의 `[[링크]]` | `wiki/` 안 `.md` 파일 이름 |
| ③ 깨진 `[[링크]]` | 모든 페이지 본문의 `[[링크]]` | `wiki/` 안 `.md` 파일 이름 |
| ④ 장부에 없는 `raw/` 파일 | `raw/` 하위 폴더까지 포함한 상대 경로 | 장부의 「원본 파일」 칸 |
| ⑤ `## 출처`가 없거나 「(확인 안 됨)」만 적힌 페이지 | 페이지 본문 | - |

- **⑤는 절이 있나만 보는 게 아니에요.** `## 출처`(또는 `## 원본`·`## Source`) 절이 있고 그 아래에 **진짜 경로가 한 줄이라도** 있어야 셈에서 빠져요. 절이 없거나 `- (확인 안 됨)`만 있으면 ⑤로 세요. **`references/진단과이음.md` 2.4의 「출처가 적힌 페이지」를 뒤집은 것과 같은 문장이에요.** 두 곳이 다르게 세면 같은 폴더를 놓고 점검은 「문제 0」, 안내 페이지는 「5/7」이라고 말하게 돼요
- **진단에서 짝을 못 찾아 「(확인 안 됨)」으로 둔 페이지가 여기 잡혀요.** 고장이 아니에요. 그 자료를 창고에 넣고 「위키에 넣어줘」라고 하시면 채워져요
- **장부를 셀 때는 ` ``` `로 열고 닫는 상자 안의 줄도 빼고 세요.** 상자 안은 보기라 진짜 자료가 아닌데 줄 모양이 똑같아서 그냥 세면 다섯 줄이 더해져요
- `raw/` 쪽은 **파일 이름만이 아니라 `raw/`부터의 상대 경로**로 견줘요. 이름만 견주면 다른 달의 같은 방 파일이 같은 것으로 잡혀요

## 3. ③ 깨진 링크를 0으로 만들지 않아요

"아직 안 만든 페이지" 후보로 봐요. **①②④⑤가 0이면 잘 굴러가는 거예요.** 0이 아니면 왜 그런지 한 줄로 적어 둬요.

## 4. 자료 넣기에서 고르는 순서 (SKILL.md 3절 2번)

- **`raw/` 아래 하위 폴더까지 전부 훑되, 이름이 `_`로 시작하는 파일과 폴더는 빼요.** 장부의 「원본 파일」 칸에는 **`raw/`부터의 상대 경로**를 적어요(예 · `카톡/2026-09/현장 단톡방_8f3a.md`). 파일 이름만 적으면 다른 달의 같은 방 파일과 구분이 안 돼요
- **`raw/_수집상태.json`이 있으면** 먼저 현황을 보고 **새로 온 것으로 잡힌 파일부터 20칸을 채우고, 남는 자리를 밀린 것으로 채워요.** 새 자료가 밀린 자료 뒤에 줄 서 있으면 며칠째 안 읽혀요
- 같은 묶음 안에서는 **폴더 이름 순, 그 안에서 파일 이름 순**이에요. 아무거나 집으면 회차마다 결과가 달라져요
- **이름이 비슷한 파일(같은 문서의 다른 버전)은 한 회차에 같이 넣어요.** 회차가 갈리면 어느 쪽이 최신인지 못 가려서 옛 검토안이 승인본으로 올라가요

## 5. 중복으로 보일 때

**이름 끝에 `(1)`·`사본`이 붙었거나 장부에 있는 파일과 크기가 같으면**, `대기`로 적기 전에 열어서 같은 자료인지부터 봐요.

- 같으면 "이건 N월 N일에 넣었어요"라고 말씀드리고, **페이지는 다시 쓰지 않고 장부에 `버림` 한 줄만** 남겨요(이유에 대표 파일 이름)
- 그래야 **장부 행 수와 `raw/` 파일 수가 계속 같아요**
- 장부에 적힌 이름과 실제 파일 이름을 맞춰볼 때는 **양쪽 다 같은 형태(NFC)로** 바꿔서 비교해요

## 6. 기존 페이지에 붙일 때 (SKILL.md 3절 4번)

- **`## 내용`을 날짜 순으로 다시 세워요.** 새 사실이 맨 아래에만 붙으면 시간 순이 깨져요
- **이미 적힌 사실과 겹치면 두 줄로 두지 말고 한 줄로 합쳐요.** 같은 금액이 두 줄로 남으면 다음 점검에서 ⑥(서로 어긋나는 내용)으로 잡혀요
- **이미 적혀 있던 문장은 지우지 않아요.** 합칠 때도 더 자세한 쪽을 남겨요
