# 자료가 쌓이면 이렇게 늘려요

지금은 손으로 넣는 1단계예요. 급하지 않아요. 1단계만으로도 위키는 굴러가요.

| 단계 | 언제 | 새로 할 수 있는 말 |
|---|---|---|
| 1. 손으로 | 지금 | "이거 넣어줘" |
| 2. 폴더가 받기 | 1~2주 뒤 | "새로 온 거 있어?" |
| 3. 메일·캘린더 | 한 달 뒤 | "이번 주 메일에서 넣을 거 골라줘" |
| 4. 정해진 시각에 | 자료 300건 넘으면 | "매일 아침에 새 자료 훑게 해줘" |

4단계는 Windows면 작업 스케줄러, macOS면 launchd로 걸어요.

**폴더 구조와 규칙은 4단계까지 안 바뀌어요.** 늘어나는 건 자료가 들어오는 방법뿐이에요.

## 자동으로 돌릴 때 지킬 세 가지

1. 자동은 **판정까지만** 하고 페이지 쓰기는 확인받은 뒤에 해요.
2. 돌리기 전에 위키 폴더를 바깥에 통째로 복사해 둬요.
3. 무엇을 했는지 `log.md`에 남겨요. 사람이 안 보는 사이에 돈 것일수록 기록이 중요해요.

## 2단계를 지금 당장 흉내 내려면

폴더를 자동으로 감시하는 건 아직이지만, 이렇게만 해도 비슷해요.
새로 받은 파일을 그때그때 `raw/`에 던져 두고, 주에 한 번 "위키에 넣어줘"라고 하면 돼요.
장부가 이미 처리한 파일을 알아보니까 몇 번을 불러도 같은 자료가 두 번 올라가지 않아요.
