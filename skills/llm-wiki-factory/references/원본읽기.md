# 원본 파일 읽기

`raw/`에는 Word(`.docx`)·엑셀(`.xlsx`)·PPT(`.pptx`)·PDF·메일(`.eml`)·사진(`.png`)이 섞여 들어와요.
순서는 SKILL.md 4절에 있고, 여기는 **글자를 어떻게 뽑는지**를 적어요. **설치할 건 하나도 없어요.**

## 1. 먼저 그냥 읽어 봐요

파일 읽기 도구로 열어서 **한글이 제대로 보이면 그걸로 끝이에요.** PDF와 사진과 텍스트는 거의 여기서 됩니다.
알파벳과 `=` 기호가 길게 이어진 글자가 보이면 열린 게 아니에요. 2번으로 가요.

## 2. 파이썬 기본 기능으로 풀어요

**라이브러리가 없다고 3번으로 넘어가기 전에 이 기본 기능을 먼저 써 봐요.**

**Word(`.docx`)와 PPT(`.pptx`)** 는 속이 zip이에요. 파이썬 기본 기능만으로 글자가 나와요.

```python
import zipfile, re
def 글자뽑기(경로, 안쪽):
    with zipfile.ZipFile(경로) as z:
        붙임 = "".join(z.read(n).decode("utf-8", "replace")
                       for n in z.namelist() if re.match(안쪽, n))
    붙임 = re.sub(r"</w:p>|</a:p>", "\n", 붙임)
    return re.sub(r"<[^>]+>", "", 붙임)

print(글자뽑기("raw/회의록.docx", r"word/document\.xml"))
print(글자뽑기("raw/시안.pptx",  r"ppt/slides/slide\d+\.xml"))
```

**메일(`.eml`)** 은 그냥 열면 한글이 `=EC=9A=B4` 같은 모양으로 깨져 보여요. 열린 게 아니에요.

```python
import email, email.policy
m = email.message_from_file(open("raw/승인.eml", encoding="utf-8"),
                            policy=email.policy.default)
print(m["subject"], m["from"], m["date"])
print(m.get_body(("plain",)).get_content())
```

**엑셀(`.xlsx`)** 은 `openpyxl`이 이미 깔려 있으면 그걸 쓰고, 없으면 Word와 같은 방식으로 `xl/sharedStrings.xml`과 `xl/worksheets/sheet*.xml`에서 뽑아요.

**PDF와 사진**은 대개 파일 읽기 도구로 그냥 열려요.

## 3. 그래도 못 읽으면 한 줄만 부탁드려요

> 이 파일은 제가 못 읽어요. 원래 프로그램에서 열어 「다른 이름으로 저장」으로 텍스트나 PDF로 저장해 주시겠어요?

그동안 그 파일은 장부에 `보류`로 둬요.

## 4. 창고에 변환본을 만들지 않아요

- 뽑은 글자는 **위키 페이지에 요약으로만** 반영해요. `raw/` 옆에 `회의록.txt` 같은 변환 파일을 만들지 않아요.
- 창고에 원본이 아닌 게 섞이면 **다음 회차에 그게 또 새 자료로 잡혀요.**
- **어떤 경우에도 `raw/` 파일을 변환본으로 덮어쓰지 않아요.** 원본을 그대로 두는 게 첫 번째 약속이에요.

## 5. 사진과 이미지

파일 이름 말고 **내용을 보고** 판정해요. 화이트보드나 문서를 찍은 사진이면 읽어서 올림, 무슨 내용인지 모르겠으면 보류예요.
