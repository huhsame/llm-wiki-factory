# 안내 페이지 · `안내.html`

## 1. 무엇인가

**위키 폴더에 놓이는 HTML 한 장**이에요. 더블클릭하면 브라우저에서 열려요. 지금 이 위키가 어떻게 생겼고, 무슨 말을 하면 되고, 지금 몇 건이 들어와 있는지를 한 화면에 보여줘요.

사용자 환경(Claude 데스크톱 앱 Code 탭)에는 발행 도구가 없을 수 있어요. **그래서 로컬 파일이 기본이고 발행은 덤이에요.**

- 자리 · **위키 루트**예요(`raw/`·`wiki/`와 형제). `wiki/` 안에 두면 옵시디언 볼트에 섞이고 목차 규칙과 헷갈려요
- 이름 · `안내.html`. 한글 이름이라 Windows 탐색기에서 바로 알아봐요
- 틀 · 이 스킬 폴더의 `templates/안내.html`

## 2. 자리표시자 목록

| 자리표시자 | 무엇 | 못 채우면 |
|---|---|---|
| `{{위키이름}}` | `CLAUDE.md` 맨 위 제목 줄. 없으면 폴더 이름 | 폴더 이름 |
| `{{한줄소개}}` | `CLAUDE.md` 제목 바로 아래 한 줄 | 그 칸 통째로 빼요 |
| `{{날짜}}` | 오늘 | 필수 |
| `{{폴더트리}}` | 4절 | 필수 |
| `{{파일역할}}` | 실제로 있는 뼈대 파일만 한 줄씩(이름 · 역할) | 있는 것만 |
| `{{숫자_페이지}}` | 페이지 장수 | `0` |
| `{{숫자_자료}}` | 창고 파일 수 | `0` |
| `{{숫자_올림}}` `{{숫자_대기}}` `{{숫자_버림}}` `{{숫자_보류}}` | 장부 상태별 줄 수 | 장부가 없으면 그 칸 통째로 빼요 |
| `{{숫자_서랍}}` | `tags.md`의 서랍 개수 | 칸 빼요 |
| `{{숫자_목차등재}}` | `N/M` 꼴 | 칸 빼요 |
| `{{숫자_출처}}` | `N/M` 꼴 | 칸 빼요 |
| `{{연결}}` | 연결된 소스 한 줄 | `아직 없어요 · 손으로 넣고 계세요` |
| `{{자동화}}` | 밤 자동화 한 줄 | `아직 없어요` |
| `{{말지도}}` | 5절 | 필수 |
| `{{다음할일}}` | 6절 · 세 줄 | 필수 |
| `{{최근기록}}` | `log.md` 맨 위 덩어리를 보고 **무엇을 몇 건 했는지만 숫자로 다시 쓴 세 줄** | 칸 빼요 |

**빈 `{{...}}`를 화면에 남기지 않아요.** 못 채우면 그 칸(제목까지)을 통째로 빼요. 화면에 중괄호가 보이면 고장 난 것처럼 보여요.

- **홑중괄호도 마찬가지예요.** `{{위키이름}}`을 `CLAUDE.md` 제목 줄에서 가져왔는데 `# {내 위키}`처럼 중괄호가 남아 있으면, 그건 아직 안 채운 틀이에요. 그대로 쓰지 말고 **폴더 이름**을 써요. 그리고 `CLAUDE.md` 쪽도 그 자리에 폴더 이름을 채워 넣어요
- **자리표시자는 파일에 한 번만 나와요.** 틀의 안내 주석에는 중괄호를 쓰지 않아요. 주석에도 같은 토큰이 있으면 통째로 바꿔 넣을 때 주석 안까지 바뀌고, 바로 아래 보기 주석이 같은 주석 안으로 빨려 들어가요. 채워 넣은 글에 `--`나 `-->`가 섞이면 주석이 일찍 닫혀서 보기 줄이 화면에 튀어나와요
- **다 채운 뒤에는 맨 위 「이 파일은 틀이에요」 안내 주석을 지워요.** 배포본에 남길 글이 아니에요

- **`{{최근기록}}`은 원문을 그대로 옮기지 않아요.** `log.md` 줄에는 페이지 이름과 거래처 이름과 판단 문장이 들어 있어요(예 · 「예산표가 두 개라 …쪽만 올렸어요」). 이 페이지는 이름이 안 들어가는 게 약속이라 **「페이지 3장을 더했어요」·「자료 15건을 정리했어요(올림 8 · 버림 4 · 보류 3)」처럼 숫자로 바꿔** 적어요. **이번에 우리가 한 일을 먼저 넣고**, 세 줄이 안 차면 그 위 회차에서 채워요

## 3. 채우는 규칙

- **숫자는 세서 넣어요. 어림하지 않아요.** `llm-wiki-inbox`가 깔려 있고 파이썬이 되면 그 스킬 `scripts/inbox_status.py`의 결과를 써요. 없으면 `references/진단과이음.md` 2.4의 세는 법 그대로 손으로 세요. 둘 다 같은 규칙이라 숫자가 같아야 해요
- **사람 이름·회사 이름·금액을 넣지 않아요.** 이 페이지는 구조 설명서지 내용 요약이 아니에요. `{{위키이름}}`과 `{{한줄소개}}`만 예외인데, 그건 사용자가 직접 쓴 한 줄이에요
- **페이지 제목도 안 넣어요.** 폴더 트리에도 `(페이지 10장)`으로만 적어요. 이걸 지켜야 나중에 발행해도 안전해요
- **외부에서 가져오는 게 하나도 없어요.** 스크립트 0 · 웹폰트 0 · 이미지 0 · 주소로 부르는 것 0. 전부 파일 안에 들어 있어요. 인터넷이 없어도 열려야 해요
- 그래서 브랜드 손글씨 글꼴은 **안 써요.** 대신 종이색 배경·크림 카드·연필 검정·형광펜 노랑 밑줄·빨간 색연필 강조로 브랜드감을 내요. 글꼴은 시스템 글꼴만요
- **어두운 화면도 돼요.** 컴퓨터가 어두운 모드면 칠판 배경에 분필 글씨로 바뀌어요
- **폰 폭(360px)에서 가로 스크롤이 0이어야 해요.** 표는 폭이 좁아지면 세로 카드로 바뀌고, 폴더 트리 상자만 그 안에서 옆으로 밀려요
- 파일 하나예요
- 맨 아래 한 줄 · "이 페이지는 자동으로 다시 만들어져요. 손으로 고치셔도 다음 갱신 때 덮어써요."

## 4. `{{폴더트리}}`

**실제 폴더를 읽어서 그려요.** 템플릿에 박힌 보기를 그대로 쓰지 않아요.

```
내위키/
├── CLAUDE.md          규칙 · 새 대화가 알아서 읽어요
├── 안내.html          이 페이지
├── raw/               원본 창고 · 파일 16개
└── wiki/
    ├── index.md       목차 · 10줄
    ├── log.md         기록 · 회차 2개
    ├── tags.md        서랍 · 13개
    ├── 장부.md         장부 · 16줄
    └── (페이지 10장)
```

- **줄맞춤은 한글 한 글자를 두 칸으로 세서 맞춰요.** 글자 수로만 맞추면 `안내.html`·`장부.md`가 든 줄만 오른쪽으로 밀려요. 맞추기 번거로우면 줄맞춤을 아예 포기하고 `├── 장부.md · 장부 · 16줄`처럼 ` · `로 이어 붙여요
- **깊이 2단계까지만**이에요. `raw/` 아래 하위 폴더는 이름과 파일 수만 적고 안을 펼치지 않아요
- 페이지는 이름을 적지 않고 `(페이지 N장)`으로요
- 실제로 없는 파일은 줄을 안 그려요

## 5. `{{말지도}}` · 말 한마디 지도 정본

**쓸 수 있는 말의 정본은 이 표예요.** 스킬 설명(description)·안내 페이지·교재·그림 설명서가 전부 이 표를 보고 맞춰요. 네 군데가 따로 놀면 학생이 교재에서 본 말을 쳤는데 아무 일도 안 일어나요.

| 말 | 무엇이 일어나나 | 어느 스킬 | 안내 페이지에 |
|---|---|---|---|
| `위키 만들어줘` · `세팅해줘` | 폴더와 뼈대 파일을 만들어요 | factory | 안 보여요(이미 만든 뒤라서) |
| `내 위키 봐줘` | 지금 상태를 표 한 장으로 보여드려요. 읽기만 해요 | factory | 언제나 |
| `계속해줘` | 백업만 하고 멈춘 진단을 이어서 해요 | factory | 안 보여요(그 자리에서만 써요) |
| `위키에 넣어줘` · `새로 넣은 자료 처리해줘` | 창고의 새 자료를 읽고 올림·버림·보류를 정해 페이지로 써요 | factory | 언제나 |
| `위키에서 ~ 찾아줘` | 목차부터 읽고 관련 페이지를 합쳐 답해요. 출처도 붙여요 | factory | 언제나 |
| `위키 점검해줘` | 목차·출처·장부가 어긋난 데를 세서 보여드려요 | factory | 언제나 |
| `뭐가 아직 안 들어갔어?` | 장부에 아직 없는 것과 판정 전인 것을 갈라서 세요 | factory | 언제나 |
| `안내 보여줘` · `안내 페이지 열어줘` | 이 페이지를 다시 채워서 열어 드려요 | factory | 언제나 |
| `둘러봐줘` | 메일과 카톡의 겉만 세어 표로 보여드려요 | inbox | 소스가 없을 때만 |
| `메일 연결해줘` · `카톡 연결해줘` | 수집을 세팅해 창고로 가져오게 이어 드려요 | inbox | 소스가 없을 때만 |
| `밀린 거 처리해줘` | 받아 둔 자료를 스무 건씩 이어서 정리해요 | inbox → factory | 소스가 있을 때만 |
| `지금까지 얼마나 들어왔어` | 새로 온 것과 밀린 것을 갈라서 세 드려요 | inbox | 소스가 있을 때만 |
| `새 메일 가져와` | 마지막으로 본 뒤에 온 것만 창고로 가져와요 | inbox | 소스가 있을 때만 |
| `밤에 알아서 돌게 해줘` | 밤마다 가져오기만 자동으로 돌게 걸어요 | inbox | 소스가 있고 자동화가 없을 때만 |
| `자동 수집 꺼줘` | 밤 자동화를 멈추거나 지워요 | inbox | 자동화가 있을 때만 |

**안내 페이지에는 「안 보여요」 줄을 빼고 상황에 맞는 줄만 넣어요.** 없는 기능의 말을 보여주면 눌렀다가 안 돼서 막혀요.

## 6. `{{다음할일}}` · 세 줄

아래 순서로 **위에서부터 세 개**를 골라요. 사람이 고르지 않아요.

1. 창고가 비어 있으면 → `위키에 넣어줘` · 먼저 자료를 `raw/` 폴더에 넣어 주세요
2. 창고에 장부에 없는 파일이 있으면 → `위키에 넣어줘` · 아직 장부에 안 적힌 자료가 N건 있어요
3. 장부에 `대기`가 있으면 → `밀린 거 처리해줘` · 대기 N건이 남아 있어요
4. 출처가 없는 페이지가 있으면 → `위키 점검해줘` · 어디서 왔는지 모르는 페이지가 N장 있어요
5. 연결된 소스가 없으면 → `메일 연결해줘` · 매번 파일을 손으로 넣지 않아도 돼요
6. 소스는 있는데 자동화가 없으면 → `밤에 알아서 돌게 해줘` · 밤에 가져오기만 돌아요
7. 페이지가 40장을 넘었으면 → `위키 점검해줘` · 주제별로 묶을 때가 됐어요
8. 위에 걸리는 게 없으면 → `위키에서 ~ 찾아줘` · 이제 물어보시면 돼요

- **같은 말이 두 번 걸리면 둘째는 건너뛰고 그다음 것을 골라요.** 1번과 2번이 같이 걸릴 일은 없지만 4번과 7번은 둘 다 `위키 점검해줘`예요
- **갓 만든 빈 위키에서도 세 줄이 나와야 해요.** 1·5·8번이 걸려서 세 줄이 채워져요

## 7. 열어 주는 방법

**만들고 나서 제가 열어 드려요.** 사용자에게 명령을 치라고 하지 않아요.

- Windows · `Invoke-Item`으로 열어요
- macOS · `open`으로 열어요
- 둘 다 안 되면 한 줄만 · "위키 폴더의 `안내.html`을 더블클릭하시면 열려요."
- 브라우저가 기본 프로그램이 아니어서 이상한 앱이 열리면 · "파일에 오른쪽 클릭 → 연결 프로그램 → 웹 브라우저를 고르시면 돼요."

## 8. 갱신 시점

**아래 일이 끝날 때마다 다시 채워요.** 물어보지 않고요.

| 언제 | 왜 |
|---|---|
| 위키를 막 만든 뒤 | 처음 보는 화면이에요. 숫자는 다 0이지만 구조가 보여요 |
| 진단·실행이 끝난 뒤 | 방금 뭐가 생겼는지 보여줘요 |
| 자료 넣기가 끝난 뒤 | 장부 숫자와 다음 할 일이 바뀌어요 |
| 점검이 끝난 뒤 | 출처·목차 숫자가 바뀌어요 |
| 카톡·메일을 연결한 뒤 | 연결 줄과 말 지도가 바뀌어요 |
| 밤 자동화를 건 뒤 | 자동화 줄이 바뀌어요 |

**갱신은 템플릿부터 다시 채우는 거예요.** 기존 HTML을 부분 수정하지 않아요. 그래야 몇 번을 돌려도 결과가 같아요. 파일 이름도 항상 `안내.html` 하나예요. `안내 (1).html`을 만들지 않아요.

## 9. 발행 도구가 있을 때

**발행은 기본이 아니에요. 먼저 여쭤보지도 않아요.** 이 스킬이 답을 기다리는 자리는 진단의 확인 질문 **딱 한 번**뿐인데(`references/진단과이음.md` 3.4), 여기서 또 물으면 발행 도구가 붙은 환경에서는 매번 두 번이 돼요. 교재와 설명서가 「딱 한 번」이라고 약속한 것과 어긋나요.

- **「발행해줘」·「인터넷 주소로도 만들어줘」라고 하실 때만** 발행하고 주소를 알려드려요
- **로컬 파일이 먼저예요.** 발행이 안 돼도 `안내.html`은 이미 만들어져 있어야 해요
- 발행하기 직전에 한 줄만 알려드려요 · "링크를 아는 사람은 볼 수 있어요. `{{위키이름}}`과 `{{한줄소개}}`에 회사 이름이 들어 있으면 말씀해 주세요."
- 이미 발행한 적이 있으면 **같은 주소를 갱신해요.** 새 주소를 또 만들지 않아요. 주소는 `CLAUDE.md` 맨 아래 규칙 절에 한 줄로 적어 둬요
