# 장부

`raw/`에 들어온 자료 **1건 = 1줄**이에요. 위키에 안 올린 것도 남아요.
상태는 넷이에요. `대기`(아직 판정 전) · `올림` · `버림`(이유 필수) · `보류`(물어볼 게 있음).
자료를 넣기 시작할 때 고른 파일을 **전부 `대기`로 먼저** 적어요. 중간에 멈춰도 자료가 안 없어져요.
「뭐가 아직 안 들어갔어?」라고 물으면 `대기`와 `보류`만 세면 돼요.
**빈 칸은 `-` 하나**로 두고, 만든 페이지 칸은 대괄호 두 개로 감싼 페이지 이름으로 적어요.

| 날짜 | 원본 파일 | 상태 | 이유 | 만든 페이지 |
|---|---|---|---|---|

아직 한 줄도 없어요. 첫 자료를 넣으면 위 표에 한 줄씩 쌓여요.

## 채우는 모양

아래는 보기예요. **표 모양이 아니라 글로 적어 뒀어요.** 표 모양이면 셀 때 진짜 자료로 잡히거든요.
날짜 · 원본 파일 · 상태 · 이유 · 만든 페이지 순서예요.

- 2026-09-19 · `운영회의_0901.docx` · 올림 · 회의 결정·금액 있음 · 만든 페이지 `9월 운영회의`
- 2026-09-19 · `계획서_최종.docx` · 버림 · 같은 문서의 이전본 v0.9 (대표 · `계획서_최종_수정.docx`) · 만든 페이지 없음
- 2026-09-19 · `IMG_2931.png` · 보류 · 무슨 화면을 찍은 사진인지 모르겠어요 · 만든 페이지 없음
- 2026-09-19 · `카톡/2026-09/보기용 단톡방_0000.md` · 올림 · 9월 일정·금액 결정이 있음 · 만든 페이지 `보기용 프로젝트`
- 2026-09-19 · `메일/2026-09/2026-09-14_a3f1b2c8_보기용 견적 회신.md` · 올림 · 견적 금액 확정 회신 · 만든 페이지 `보기용 프로젝트`

진짜 장부에 적을 때는 맨 위 표에 `|` 로 나눈 한 줄로 넣고, 만든 페이지는 대괄호 두 개로 감싸요.
뒤 두 줄처럼 자료가 하위 폴더에 있으면 **`raw/`부터의 상대 경로**를 적어요.
파일 이름만 적으면 다른 달의 같은 파일과 구분이 안 돼요.

**세는 법** · 장부 행 수를 셀 때는 맨 위 표의 줄만 세요. 이 보기 줄은 표가 아니라서 안 잡혀요.
