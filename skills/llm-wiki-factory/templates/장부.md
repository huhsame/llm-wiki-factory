# 장부

`raw/`에 들어온 자료 **1건 = 1줄**이에요. 위키에 안 올린 것도 남아요.
상태는 넷이에요. `대기`(아직 판정 전) · `올림` · `버림`(이유 필수) · `보류`(물어볼 게 있음).
자료를 넣기 시작할 때 고른 파일을 **전부 `대기`로 먼저** 적어요. 중간에 멈춰도 자료가 안 없어져요.
「뭐가 아직 안 들어갔어?」라고 물으면 `대기`와 `보류`만 세면 돼요.
**빈 칸은 `-` 하나**로 두고, 만든 페이지 칸은 대괄호 두 개로 감싼 페이지 이름으로 적어요.

| 날짜 | 원본 파일 | 상태 | 이유 | 만든 페이지 |
|---|---|---|---|---|
| 2026-09-19 | 운영회의_0901.docx | 올림 | 회의 결정·금액 있음 | [[9월 운영회의]] |
| 2026-09-19 | 계획서_최종.docx | 버림 | 같은 문서의 이전본 v0.9 (대표: 계획서_최종_수정.docx) | - |
| 2026-09-19 | IMG_2931.png | 보류 | 무슨 화면을 찍은 사진인지 모르겠어요 | - |
